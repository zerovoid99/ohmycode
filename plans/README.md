## Findings considered and rejected

- PostgreSQL accepting cleartext password auth without TLS: same as libpq's default; not changed.
- Tree-sitter grammars on 0.23.x with the 0.25 runtime: still ABI-compatible; bump only when needed.
- Extension guide gaps (`Diagnostic.code`, relative `require`, `@types/node` clash): already documented.
- Adding a formatter/linter: not worth it for a one-person repo yet.

- Not audited: `OhMyCode/Editor/Vim`, `OhMyCode/Terminal` emulation details (libghostty), `OhMyCode/Syntax/TextMate` regex translation, UI layout code beyond the files cited.
